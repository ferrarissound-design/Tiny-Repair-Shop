# Tiny Repair Shop 🔧

A small, cozy Roblox repair-shop game built in **Luau** and managed with **Rojo**.

## Current playable MVP

The repository already contains a complete first loop:

1. Walk to the customer at the front counter.
2. Accept a repair request.
3. Go to the workbench.
4. Inspect the broken item.
5. Follow the repair steps using Roblox \`ProximityPrompt\` interactions.
6. Test the item.
7. Earn money and reputation.
8. Take another job.

Three repair-item families are included:

- Desk fan
- Portable radio
- Toy car

Each item can have more than one hidden fault, so the exact repair is not known until inspection.

There is also a small chance to find forgotten coins inside an item while opening it.

## Roblox-first design

- **Luau only** for runtime code.
- Touch, controller, and keyboard friendly through \`ProximityPrompt\`.
- Mobile-friendly HUD.
- Server-authoritative rewards and repair progress.
- English by default, Japanese UI automatically when the Roblox locale starts with \`ja\`.
- The workshop is generated by the server, so an empty Baseplate is enough for the first test.
- Money and reputation use DataStore persistence when API access is available.

## Rojo

From the repository folder:

\`\`\`powershell
rojo serve
\`\`\`

Then connect Roblox Studio with the Rojo plugin.

The project entry point is:

\`\`\`
default.project.json
\`\`\`

Press **Play** in Studio after syncing. The server builds the workshop automatically.
